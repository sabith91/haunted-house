# Interactive 3D Haunted House Simulation (Roll 2107091)
C++ / OpenGL 1.x / GLUT. Single source file, no external assets.

Build: `make` (Linux: `sudo apt install freeglut3-dev`).
Windows (Code::Blocks / MinGW): link `-lfreeglut -lglu32 -lopengl32`.

Controls: WASD move (Shift run) | mouse or arrows look | F flashlight | E door/gate | L lightning
1 gate | 2 entrance hall | 3 bedroom | 4 railway | H help | M mouse-look on/off | Esc quit
